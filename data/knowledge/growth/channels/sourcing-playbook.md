# Playbook de sourcing — trouver les proprios A/B/C à la main

*Recherche web datée 2026-07-11 (growth-intel-001). Méthode opérationnelle pour l'outreach
manuel du fondateur. Données publiques uniquement, RGPD-aware, pas de scraping massif.*

> Rappel garde-fou : on **sème 10 relations à la main**, on ne construit pas un scraper. Ce
> playbook est reproductible mais reste à volume raisonnable (quelques dizaines de cibles
> qualifiées, pas des milliers). Le fondateur envoie. Complète `channels/competitor-platforms.md`
> (méthode générale) et `channels/facebook-groups.md` (canal FB) avec du concret.

## PARTIE 1 — Filtrage précis par plateforme

### Spotahome (persona B)
- **URL de recherche** : spotahome.com → ville **Paris**, filtre **type "Entire property"**
  (studios/apparts entiers = plus probable un vrai proprio qu'une chambre en coloc pro).
- **Filtres durée** : viser les annonces "monthly" / séjours longs (moyen terme).
- **Signaux "vrai particulier"** (vs conciergerie pro) : un **seul bien** ou 2-3 max sous le même
  prénom ; description écrite à la première personne ; prénom seul affiché.
- **Indice de douleur à noter** : le bien y est listé = il paie/paiera la commission (Plus 8% ou
  standard opaque). Douleur latente = commission + support.
- **Contact** : messagerie plateforme (le fondateur écrit via le compte) OU croiser le prénom +
  quartier + type de bien pour retrouver un profil public ailleurs (LinkedIn/FB) — **sans
  constituer de fichier de données perso**, juste pour un contact B2B pertinent.

### Wunderflats (persona B)
- **URL** : wunderflats.com → **Paris**, meublé, durée 1-12 mois.
- **Signaux particulier** : idem Spotahome. Beaucoup de biens y sont d'agences/relocation → **bien
  filtrer** pour ne garder que les particuliers.
- **Indice de douleur** : 12% TTC sur le contrat total. Fort chez les biens à loyer élevé (le %
  fait mal en valeur absolue).
- **Contact** : messagerie plateforme.

### Lodgis (persona B) — attention
- **URL** : lodgis.com → **Paris**, location meublée.
- **Nuance** : Lodgis est une **agence**, beaucoup de biens sont sous mandat agence, pas des
  particuliers directs. **Cibler les proprios, pas les biens gérés.** Plus dur à joindre en direct.
  → Prioriser Spotahome/Wunderflats/Airbnb/Leboncoin sur Lodgis pour le sourcing direct. Lodgis
  sert surtout de **preuve de tarif** (15%) dans l'argumentaire, pas de vivier de contacts faciles.

### Leboncoin (persona C)
- **URL** : leboncoin.fr → catégorie **Locations**, **Paris (75)**, type **Meublé**.
- **Mots-clés dans la recherche** : "meublé", "bail mobilité", "moyen terme", "courte durée",
  "3 mois", "6 mois", "temporaire", "pied-à-terre".
- **Signaux persona C (auto-gestion à aider)** : annonce écrite par un **particulier** (pas
  "agence"), mentions **"dossier complet demandé"**, **"sérieux s'abstenir"**, **"CDI exigé"** →
  proprio qui galère avec le tri et veut du filtrage.
- **Indice de douleur** : dizaines de dossiers, pas de bail carré, pas de signature.
- **Contact** : messagerie LBC (le fondateur). Ne pas extraire de tel/email non destinés au public.

### PAP (persona C)
- **URL** : pap.fr → **Location**, **Paris**, **Meublé**, filtrer durée si dispo.
- **Signaux** : 100% particuliers (c'est la promesse PAP) → **vivier persona C pur**. Coordonnées
  souvent visibles car PAP est "entre particuliers" — rester dans un usage de **contact B2B
  ponctuel**, pas de collecte de masse.
- **Indice de douleur** : identique LBC — tri + bail + signature.

### Airbnb (persona A)
- **URL** : airbnb.fr → **Paris**, dates couvrant **28+ nuits** (déclenche l'affichage "monthly
  stays" / tarif mensuel).
- **Signaux persona A** : hôte proposant du **long séjour / mensuel**, description mentionnant
  "monthly", "long stay", "professionals", "relocation". Souvent des hôtes qui **basculent déjà**
  vers le moyen terme pour fuir la réglementation.
- **Indice de douleur** : plafond 90 nuits, changement d'usage, amendes, micro-BIC 30% (cf.
  `competitors/commissions-et-modeles.md`). Douleur réglementaire = la plus forte du marché.
- **Contact** : messagerie Airbnb. Croiser prénom + quartier avec les groupes FB d'hôtes.

## PARTIE 3 — Grille de scoring des cibles (prioriser)

Pour chaque cible sourcée, noter les critères. **Chaud = attaquer en premier.**

### Critères (chacun +1 si vrai)
| # | Critère | Pourquoi |
|---|---|---|
| 1 | **Particulier** (pas agence/conciergerie pro) | C'est notre ICP décideur |
| 2 | **Meublé** | Fit produit |
| 3 | **Paris intra-muros** | Périmètre lancement |
| 4 | **Durée flexible affichée** (1-24 mois, "monthly", "temporaire") | Fit bail Code Civil |
| 5 | **Douleur explicite visible** (commission subie / plainte réglementation / "dossier complet demandé" / auto-géré) | Accroche d'outreach prête |
| 6 | **Bien vacant ou dispo bientôt** (annonce active, dates ouvertes) | Besoin immédiat = conversion rapide |
| 7 | **Moyen de contact public identifié** (messagerie plateforme / post FB) | Actionnable sans effort |
| 8 | **Non-résidence-principale plausible** (pied-à-terre, 2e bien, hôte multi-nuitées) | Conformité légale du bail |

### Barème
- **CHAUD (6-8 pts, dont critères 1+5+6 obligatoires)** : douleur claire + besoin immédiat +
  joignable. → Message perso rédigé et envoyé en **priorité 1**. Objectif : ce sont eux les 10
  premiers baux.
- **TIÈDE (4-5 pts)** : fit produit mais douleur ou timing moins nets. → Message perso, **relance
  planifiée**, ou nurturing via valeur (groupe FB).
- **FROID (≤3 pts, ou critère 1 = agence, ou 8 = résidence principale probable)** : ne pas
  contacter maintenant. Si critère 8 échoue (résidence principale) → **exclure** (garde-fou légal,
  cf. anti-personas ICP).

### Signaux d'EXCLUSION immédiate (peu importe le score)
- Agence / conciergerie pro (pas notre décideur).
- Résidence principale du locataire visée (risque requalification — hors périmètre).
- Proprio cherchant à **déléguer toute la gestion** / voulant une GLI (pas notre produit).
- Hors Paris (vague ultérieure).
- Meublé de tourisme pur < 1 mois systématique (pas le fit).
