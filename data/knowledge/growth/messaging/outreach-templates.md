# Messaging — value props, objections, templates d'outreach

**Règle d'or** : ces templates sont des **points de départ**. Chaque message envoyé est
personnalisé sur la douleur SPÉCIFIQUE observée chez la cible (son annonce, son post). Le
copier-coller brut = spam = zéro conversion + risque ban. Le fondateur envoie ; l'agent prépare.

Ton : direct, humain, court, une seule idée + un CTA simple. Français naturel. Jamais corporate.

## Value props (par persona)

- **A (réfugié Airbnb)** : légal 1-24 mois, stable, sans le stress réglementaire ni le turnover,
  sans se bloquer 3 ans. Vous gardez la main.
- **B (commissions)** : **0% de commission** sur votre loyer. 29€ fixe/mois quand c'est loué,
  **gratuit** en tant que proprio fondateur. Vous gardez 100% de votre loyer.
- **C (auto-gestion)** : candidatures **déjà filtrées** (dossier vérifié), **bail conforme**
  généré + **signature en ligne**, sans commission et sans déléguer la gestion.

CTA universel (bas engagement) : *"Je vous publie votre bien avec vous, gratuitement, ça prend
10 minutes. Ça vous dit d'essayer ?"*

- **J+3** : *"Bonjour {{prénom}}, je me permets un petit rappel — l'accès pionnier gratuit est
  limité aux 50 premiers proprios. Si vous voulez que je publie votre bien avec vous (10 min),
  je m'en occupe. Sinon aucun souci, bonne continuation !"*
- **J+7 (dernière)** : *"Dernier message promis 🙂 Si un jour vous voulez tester une location
  sans commission, ma porte est ouverte : {{lien}}. Bonne journée !"*
- Après J+7 sans réponse : on lâche. Pas d'insistance (marque + délivrabilité).

## Objections → réponses

| Objection | Réponse |
|---|---|
| "C'est quoi le bail Code Civil, c'est légal ?" | Oui, art. 1708 s. du Code civil, pour la location **hors résidence principale** (meublé temporaire, pied-à-terre, mobilité). On génère un bail conforme + diagnostics annexés. |
| "Et si le locataire ne paie pas ?" | Vous restez le seul interlocuteur (comme aujourd'hui). Le bail est ferme, résiliation rapide possible. On ne gère pas les impayés — on n'est pas un gestionnaire, on est l'outil. |
| "Pourquoi c'est gratuit / c'est quoi le piège ?" | Gratuit pour les 50 premiers proprios (offre de lancement). Ensuite 29€/mois **seulement quand c'est loué**. Jamais de commission sur votre loyer. Pas de piège, on veut des pionniers. |
| "Je suis déjà sur Spotahome, pourquoi changer ?" | Vous pouvez faire les deux. La différence : chez nous, **0% de commission** — vous gardez tout votre loyer. Testez avec un bien, sans risque. |
| "J'ai pas le temps" | Justement — je le publie **avec vous en 10 min**, et les candidatures arrivent déjà filtrées. |
| "Vous avez combien de locataires ?" | On démarre — c'est pour ça que l'accès proprio est gratuit et que je vous accompagne perso. Les premiers biens attirent la demande (expats, mobilité). |
